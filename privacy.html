Overview

CrowdReply is a community reply management tool for social media page administrators. It can retrieve page posts and comments, prepare suggested replies using artificial intelligence, and allow an authorised page administrator to review, edit, approve, reject or post those replies.

Information processed

CrowdReply may process social media page content such as post text, comment text, comment identifiers, page identifiers, timestamps and reply status. It may also process technical information needed to operate the service, such as access tokens and application credentials.

How information is used

Information is used only to provide the CrowdReply service, including retrieving comments, checking whether a page has already replied, generating suggested responses, displaying those suggestions to the page administrator and posting replies only when authorised.

Artificial intelligence processing

Comment and post text may be sent to OpenAI to generate suggested replies. CrowdReply is designed so that page administrators can review and edit suggestions before they are posted.

Data sharing

CrowdReply does not sell personal data. Information may be processed by service providers necessary to operate the product, including Meta for Facebook platform access and OpenAI for AI-generated reply suggestions.

Data retention

CrowdReply stores only the information needed to operate the reply workflow. Data may be removed when it is no longer needed for the service or when a valid deletion request is received.

Security

Access tokens, application secrets and API keys are treated as confidential credentials and should be stored securely. Administrators are responsible for keeping their account credentials private.

Your choices

Page administrators can stop using CrowdReply at any time by revoking the app's access in Meta settings and deleting any locally stored CrowdReply data.

Data deletion

Instructions for requesting deletion are available on the Data Deletion page.

Contact

For privacy or data questions, please use the Issues section of the public CrowdReply GitHub repository.
